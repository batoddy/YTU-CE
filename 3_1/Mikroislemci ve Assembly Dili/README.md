</br> DosBox Terminal Komutları
</br> 
</br> MOUNT C C:/[kodların bulunduğu dır]
</br> 
</br> DIR DENE\*                -> Adının başında DENE olan dosyaları getirir
</br> 
</br> EDIT TANITIM1.ASM         -> Yeni dosya açar
</br> 
</br> MASM TANITIM1.ASM         -> .obj dosyasına çevirme
</br> 
</br> LINK TANITIM1.OBJ         -> .exe executable dosyaya çevirir
</br> 
</br> TANITIM1                  -> TANITIM1 dosyasını çalıştırır
</br> 
</br> DEL TANITIM1              -> TANITIM1 dosyasını siler.
</br> 
</br> DEBUG TANITIM1.EXE        -> Debug işlemi
</br> -U        -> Unassemble
</br> -R        -> Register
</br> -T        -> Trace
</br> -D DS:0   -> Data Segmentini 0dan itibaren göster (SS: Stack Segment, DS: Data Segment, CS: Code Segment)
</br> -G        -> Terminate remaining steps
</br> -Q        -> Quit debug
